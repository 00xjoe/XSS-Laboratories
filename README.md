# XSS Laboratories 

A comprehensive collection of Cross-Site Scripting (XSS) laboratories for learning and practicing web security concepts.

## Overview

XSS Laboratories is a platform I created containing multiple progressive labs designed to teach various XSS attack vectors and defense mechanisms. All labs were independently solved and developed through hands-on research.

##  Credits

Created and solved by [@00xjoe](https://github.com/00xjoe) — independently researched, tested, and verified.

## Labs Included

- **Lab 1**: Introduction to XSS Basics
- **Lab 2**: Stored XSS Attacks
- **Lab 3**: DOM-based XSS
- **Lab 4**: Advanced XSS Techniques
- **Lab 5**: Edit/View Functionality XSS
- **Lab 6**: Filter Evasion Techniques
- **Lab 7**: Real-world XSS Scenarios
- **Lab 8**: XSS in Modern Web Apps
- **Lab 9**: Comprehensive XSS Challenge
- **Final Lab**: Culmination Challenge

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/00xjoe/XSS-Laboratories.git
```

2. Navigate to the project folder:
```bash
cd XSS-Laboratories
```

3. Open the main page in your browser:
```bash
open index.html
```
Or simply double-click `index.html` in your file explorer.

4. Start with Lab 1 and progress through the challenges!
